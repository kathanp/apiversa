# GW-03 — Upstream per bundle

Author-written eval, 2026-11-08. There is no external issue. This is a weak bar.

Public sources, checked 2026-11-08:

- GW-01 and GW-02 call one upstream URL the host set. CORE-28 already keeps two bundles in one process.
- A second bundle needs its own URL. The host supplies the map. The library still calls `fetch` once and only at a URL from that map.

Bundle `billing` is sent to the billing URL. The body is upgraded and downgraded. An unknown bundle name is `AV-E001` and `fetch` is not called. Node and Spring write the same fixture bytes.
