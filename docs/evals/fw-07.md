# FW-07 — Lambda adapter

Author-written eval, 2026-11-07. There is no external issue. This is a weak bar.

Public sources, checked 2026-11-07:

- Amazon API Gateway payload format 2.0 is the current Lambda proxy event. The body is a string and may be base64. https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-develop-integrations-lambda.html
- The Node adapters today are HTTP frameworks. A Lambda function does not use those routers.

`@apiversa/lambda` upgrades the event body, calls the handler once, and downgrades the response. It does not call AWS. A 1.0 event is `AV-E022`.
